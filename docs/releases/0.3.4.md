# ClipStream 0.3.4

A little more room for your next idea.

- A refreshed teal palette, larger clip rows, and a clearer search field.
- Drag the header to move the popup; resize it with the bottom-right grip.
- Your chosen size is remembered when you close and reopen the popup.
- A visible resize grip in every theme, with row actions that follow the layout.
- A redesigned README with original artwork and real app screenshots.

Download **ClipStream-Setup-0.3.4.exe** and press **Ctrl+Shift+V** to open your history.

History stays on your device. Existing history and preferences are retained when updating.

## Validation

The UI implementation passed 19 automated test cases and 10 Windows desktop interaction checks before release preparation. The release workflow rebuilds the installer and reruns the automated suite.
