# ClipStream 0.3.3

Released October 5, 2026.

## Updated branding

- Rounded C symbol from Logo Concept 03, with its orange accent and Sora SemiBold lettering.
- Matching branding in the popup, Settings, system tray, executable, shortcuts, and uninstall entry.
- Light and dark logo variants for the app and GitHub README.
- Windows icons at eight sizes, from 16 to 256 pixels, plus a 512-pixel PNG.
- Installer welcome and completion artwork, with a matching logo on the other setup pages.
- Refreshed README screenshot and badges.

The wordmark is converted to SVG paths, so it renders without an installed Sora font.
The bundled font is licensed under the SIL Open Font License; its license is in
[resources/fonts/OFL.txt](../../resources/fonts/OFL.txt).

## Install or update

Download **ClipStream-Setup-0.3.3.exe** from the
[release assets](https://github.com/Razee4315/clipstream/releases/tag/v0.3.3)
and run it. Windows x64; no administrator access required.
The installer closes a running instance before updating it. Clipboard history is
stored separately from the application files.

Press **Ctrl+Shift+V** to open ClipStream.

## Validation

The Windows release build and automated regression suite pass. The popup and
Settings were visually checked in light and dark mode. Installer artwork was
rendered at high resolution, and the compiled installer was checked to contain
the rebuilt application.

For the previous performance and cursor-positioning changes, see the
[0.3.2 release details](0.3.2.md). The complete version history is in the
[changelog](../../CHANGELOG.md).
