## ClipStream 0.3.0

A refreshed clipboard manager with a cleaner interface, a new logo, and a faster way to find what you copied.

### What’s new
- Roomier overlay with All clips, Pinned, Text, Images, and Links filters.
- Full clip previews, with an explicit reveal control for sensitive text.
- Pause/resume capture and create snippets directly from the overlay.
- New blue clipboard-and-stream logo in the app, system tray, and installer.
- Ctrl+Space to preview, Ctrl+P to pin, and Ctrl+F to search.

### Fixes
Search now handles URLs, paths, punctuation, and app names. Selection stays stable as history changes. Copying preserves whitespace. Pausing cancels pending image captures, missing images cannot paste stale clipboard data, existing snippets stay pinned, and retention preserves the intended number of unpinned clips.

### Install
Download **ClipStream-Setup-0.3.0.exe** below and run it. Open ClipStream with **Ctrl+Shift+V**. Windows x64; no administrator access required.

Validated with a Windows release build and nine automated regression tests.
